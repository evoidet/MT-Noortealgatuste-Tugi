## Reliability

Committed draft/review/attachment work no longer fails solely because secondary audit recording fails. Delivery STARTED/SENT/REJECTED records retain their stricter behavior because they prevent unsafe automatic retransmission. Failed streamed responses close instead of hanging. AI provider calls have explicit time limits.

Archive keys use canonical source data and original-attachment hashes. Corrected source produces a new generated file; equivalent retries reuse the matching version. Old remote files remain untouched. Local tests exercise invoice archival success followed by failed finalization, correction, retry and immutable final status. SMTP ambiguity still requires the existing delivery-reconciliation procedure; automatic retries cannot prove exactly-once delivery after an unknown provider outcome.

Local PGlite tests apply it twice over pre-existing legacy rows and verify preserved data and schema access. The full migration/state-transition suite passes.

Apply migration 010 before the new application version serves archive operations. Old application code tolerates the additive columns; the new code expects them.
